# Pigment Dark

Handcrafted dark theme for [Notepad++](https://notepad-plus-plus.org/).

Based on the theme colors of Primer, the design theme for GitHub.

**Please note:**

These themes are still under heavy development, so not all programming languages may be fully supported.
Please report any issues via an issue ticket.


## Install:

Simply download `Pigment Dark.xml` and copy it to the Notepad++ themes folder.
